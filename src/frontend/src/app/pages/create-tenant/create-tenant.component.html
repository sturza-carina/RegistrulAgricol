Ce este un Tenant?

În acest ecosistem, un Tenant reprezintă o entitate administrativă independentă (ex. o Primărie sau un UAT). Fiecare tenant operează în propriul său mediu izolat, asigurând securitatea și confidențialitatea datelor registrului agricol pentru fiecare localitate în parte.

Despre Codul SIRUTA

SIRUTA (Sistemul Informatic al Registrului Unităților Teritorial-Administrative) este un cod unic la nivel național, atribuit fiecărei localități din România. Acest cod este esențial pentru identificarea și integrarea precisă a primăriei în bazele de date centrale.
